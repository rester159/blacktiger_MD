# Black Tiger MD v2.0.1

Hardware boot fix for the v2.0 black screens reported by PRETTY MAZE (Mega Sg) and ROBOT-RANDOM (Sega Genesis Model 3). Thank you both for testing every build.

- **Black screen at power-on:** the game set up the controllers twice, and the second pass froze those consoles. It now happens once. Holding MODE at power-on is no longer needed.
- **Black screen after a reset:** a reset now puts the sound hardware, controller ports and cartridge back to their starting state before the game starts, so it no longer repeats the startup while the sound processor is running.
- **Controllers:** pads are read in 3-button mode. The game uses no X, Y, Z or MODE button.
- **Start-up waits:** a stuck Start button or sound driver can no longer hold the boot on a black screen.

Confirmed on hardware with the test builds: power-on on the Mega Sg and the Model 3, and reset on the Mega Sg. Reset on the Model 3 has not been reported yet.

Saved scores, options and DIP settings carry over.

Unchanged: the name-entry screen layout still differs from the arcade. The Round 5 hardware crash reported for v1.9.6 has not been reproduced.
