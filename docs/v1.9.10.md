# Black Tiger MD v1.9.10

Hardware boot fix for the reports by ROBOT-RANDOM (Sega Genesis Model 3, black screen since v1.9.3) and PRETTY MAZE (Mega Sg, no boot on v1.9.4 and v1.9.8).

- **Black screen at power-on or after reset:** the game now always starts with a full cold boot, so it no longer depends on leftover memory contents. The cartridge startup code skipped clearing work RAM whenever the controller-port registers read as already set. That happens after the reset button and can also happen at power-on on some consoles. The game then started from leftover memory and could crash or hang on a black screen. Whether it booted varied from one build to the next, which is why some versions worked and others did not. The game's save memory is also switched out before the first data is read from the cartridge.

In testing, a reset from random memory crashed v1.9.9 every time and boots v1.9.10 to a running title every time. This was tested in an emulator only, not yet on a Model 3 or Mega Sg. Reports from those consoles are welcome.

Saved scores, options and DIP settings carry over.

Unchanged: the name-entry screen layout still differs from the arcade. The Round 5 hardware crash reported for v1.9.6 has not been reproduced.
