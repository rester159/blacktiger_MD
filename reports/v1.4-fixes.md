# v1.4: ground blobs, Home navigation, and high scores

Ground crawler bodies now finish the death clip after weak-hit recovery. The original terrain/jump callback could resume movement while the native body's contact state remained disabled. The fix intentionally ends that recovery path, including bouncing and airborne bodies; it preserves strong-hit scoring and weak-hit no-score behavior. The source trace test keeps exact comparisons before this intentional divergence and checks bounded retirement afterward. Cartridge tests also check that all three bodies leave the actor pool.

Home Up/Down cycles through Play, Boss Rush, and Options, with Debug included only after unlocking it. Existing horizontal controls remain available. Controller tests cover forward/reverse navigation, wrapping, and opening Options with A.

High scores use two 16-byte records in odd-address cartridge SRAM at $200001–$20007F. Each record stores a format signature, score, and complemented score. Writes invalidate the destination signature first and commit its first byte last, keeping the previous record intact. Records with invalid signatures, complements, or out-of-range scores are ignored. A new or invalid save starts at the original 20,000-point high score. Unchanged or lower scores do not rewrite SRAM.

SRAM briefly overlays upper cartridge ROM. Interrupts, DMA, and the Z80 are quiescent during access, and ROM mapping is restored before normal processing resumes. Runtime tests use the linked cartridge in Genesis Plus GX, carry save memory across unload/reload, verify an earned gameplay score persists, corrupt each record byte, and simulate interruption after every individual write. Actual flash-cartridge hardware has not been tested.

The Home version stamp and source README are v1.4. Generated ROMs and original arcade assets remain local and excluded from Git.

Validation: all 173 Makefile test scripts passed against the final cartridge, along with the all-level performance profile, detailed runtime profile, and 48 sprite pixel fixtures. The strict packager accepted `blacktiger_MD_v1.4.bin` (4,194,304 bytes; SHA-256 `bdadf460bb3d7cf831f7ac3e42d714bff87c84937b5061e41dc3891f49b177a4`). Busy sequences can still repeat rendered frames; this release does not claim full rendering rate on every route. The source-only Git index audit passed.
