# v1.6: Arcade attract sprite flips

The Arcade attract demo stores sprite attributes in the original SAT format, where horizontal flip is bit 3 (`0x08`). The renderer passed that whole mask to SGDK's `TILE_ATTR_FULL`, which expects a boolean and shifts it into the attribute word. Right-facing demo characters therefore received an invalid attribute. The renderer now extracts the one-bit value before building the hardware sprite attribute.

The menu version stamp is now v1.6. The README migration note reflects the new ROM filename; copy the v1.5 battery save to the v1.6 filename when updating so the emulator continues to load existing records.
