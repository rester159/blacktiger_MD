# Black Tiger MD v1.9

## Changes since v1.8

- Reduce terrain upload batches from 32 to 24 tiles, saving 256 bytes of stack space while retaining the scoped buffer lifetime introduced in v1.8.
- Update VERSION and the title-screen stamp to v1.9.
- Add instruction-level stack sampling for NTSC and PAL hardware identification with 60 Hz VDP timing. The sampled stack/heap margin increases from 118 to 374 bytes across cold boot, repeated fire and all-round transitions.
- Add an input-driven regression for opening Round 8's lower healing wall from the adjacent pole. Map placement and hitboxes are unchanged. Full natural traversal and collection are not covered.
- Support PicoDrive's libretro system-RAM interface in the diagnostic runner and add a repeatable cold-boot/repeated-fire smoke check.
- Correct the itch page copyright paragraph's game name.

The release retains the v1.8 chest-flame anchor, held-weapon sprite priority, boss-room camera/gate fixes, shop navigation/bat cleanup, quieter FM music, round-ready notice and memory fixes. See [v1.8 fixes](v1.8-fixes.md).

## Compatibility limits

The fire-triggered corruption reported on a PAL console modified to 60 Hz with Mega EverDrive Pro and the older Genesis Model 3 issue remain unconfirmed. Emulator tests do not establish a physical-hardware fix. No hardware was available. This release is a graphics-memory robustness improvement, not a confirmed fix for those reports.

Round 8 tip: grab the pole next to the lower healing wall, release Up and attack right five times. Holding Up moves the attacks above the wall. A full route and reward pickup still require further checking.
